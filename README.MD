# Mini Task Tracker

A full-stack task management application built with React,
TypeScript, Express, and in-memory storage.

## Features

- Create tasks
- View tasks
- Update tasks
- Delete tasks
- Task status management
- Client-side form validation
- Server-side request validation
- RESTful API
- Error handling
- Responsive user interface

## Tech Stack

### Frontend

- React
- TypeScript
- Vite
- Fetch API
- CSS

### Backend

- Node.js
- Express
- TypeScript
- In-memory storage
